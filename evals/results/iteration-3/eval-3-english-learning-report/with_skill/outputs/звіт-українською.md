# Звіт: Інтерес до вивчення англійської мови на Wikipedia

## Анотація

Аналіз інтересу до англійської мови (як проксі для потенціалу ринку мовного навчання) на німецькій, французькій, іспанській, польській та турецькій Wikipedia показує **різні сценарії зростання та спаду**, що вказує на три чіткі пріоритети для запуску застосунку.

## Ключові висновки

### 1. **Турецька Wikipedia — золотий пошук** 🎯
- **Єдина мова, де інтерес ДО АНГЛІЙСЬКОЇ ЗРОСТАЄ** (+7% відносного приросту)
- Хоча абсолютна аудиторія невелика (7K views/місяць), це компенсується:
  - **Найвищою питомою цікавістю** (65.3 views на мільйон views всієї Wikipedia)
  - Позитивним трендом на фоні платформ-wide спаду
  - Високою якістю даних (90% довіри, мало ботів)
- **Рекомендація**: Почати MVP-тестування саме з турецького ринку. Це свідчить про нерозривну потребу й готовність до засвоєння.

### 2. **Іспанська Wikipedia — солідна база користувачів** 👥
- **Найбільша абсолютна аудиторія** серед п'яти мов (26K views/місяць)
- Статус "flat" (-8%) означає, що скорочення в основному через платформ-wide тренд
- Друга за величиною питома цікавість (47.7 на мільйон)
- Репрезентує 500+ мільйонів іспаномовних користувачів світу
- **Рекомендація**: Паралельно з турецькою або відразу після успіху там. Гарна база для забезпечення швидкого зростання MAU.

### 3. **Французька Wikipedia — вибути з гри** ⛔
- **Найбільше скорочення інтересу** (-13% відносного приросту)
- Найнижча питома цікавість (26.7 на мільйон) серед п'яти
- Хоча довіра МАКСИМАЛЬНА (100), тренд явно негативний
- Може вказувати на насичення ринку або конкуренцію від інших джерел
- **Рекомендація**: Дослідити французькі конкуренти, але це НЕ пріоритет для MVP.

### 4. **Польська Wikipedia — можливо пізніше** 📌
- Середнього розміру аудиторія (8K views/місяць), але скорочується (-10%)
- Питома цікавість вище за французьку, але нижче за іспанську
- **Рекомендація**: Монітор для моменту стабілізації, потенціал розширення після успіху в Туреччині/Іспанії.

### 5. **Німецька Wikipedia — дані ненадійні** ⚠️
- Величезна забруднення ботами (73% views — автоматичний трафік)
- Важко розрізнити справжній людський інтерес
- Близький до нульового приросту (-1%), але цифра невідійсна
- **Рекомендація**: Залишити для етапу 2, коли будуть інші докази попиту.

## Методологія

- **Дані**: Wikimedia pageviews API (офіційний трафік Wikipedia)
- **Період**: 24 місяці (вересень 2024 – серпень 2026)
- **Проксі**: "Англійська мова" (універсальна стаття всіх Wikipedia)
  - Вимірює цікавість до мови, не саме до "навчання"
  - Більш надійна альтернатива, ніж пошук по "learning English"
- **Метрики**:
  - `relativeGrowth` = зміна ДОЛІ від всього трафіку Wikipedia (очищено від платформ-wide трендів)
  - `robustGrowth` = абсолютна зміна views
  - `perMillion` = нормалізовано на розмір кожної Wikipedia (справедливе порівняння)

---

## Обмеження

1. **Wikipedia ≠ навчання**: Трафік на "Англійська мова" вимірює ЦІКАВІСТЬ, не готовність платити за курс
2. **Виключення**: Базування на дозвіл редакторів — якби не було англійської на якійсь Wikipedia, то тема не вимірюється
3. **Ботів**: Німецька особливо забруднена автоматичним трафіком
4. **Платформ-wide спад**: Усі Wikipedia втратили трафік у 2025–26 (AI в пошуку), тому дивимось на ДОЛЮ, а не абсолютні числа

---

## Висновок

**Турецька та іспанська Wikipedia — ваші перші цілі**. Турецька показує нерозривну потребу (єдина растуча), іспанська дає масштаб. Відкладіть французьку, проведіть дослідження конкурентів німецької. Це дозволить зосередитися на ринках з найбільшим потенціалом ROI для MVP.
