# Практичний посібник: Як зібрати дані про інтерес до астрономії на українській Wikipedia

## Крок за кроком

### Крок 1: Доступ до інструменту Pageviews Analysis

1. Перейдіть на сайт: [pageviews.wmcloud.org](https://pageviews.wmcloud.org/)
2. Ви побачите три основні вкладки: **Pageviews**, **Massviews**, **Langviews**

### Крок 2: Вибір методу аналізу

Залежно від того, скільки статей ви хочете аналізувати, виберіть один із методів:

#### **Метод 1: Аналіз окремих статей (Pageviews)**
- **Найкраще для**: 1-10 конкретних статей про астрономію
- **Приклади статей**: "Астрономія", "Сонце", "Місяць", "Планета", "Телескоп"
- **Як це робити**:
  1. Введіть назву статті українською мовою
  2. Встановіть часовий період (мінімум 6 місяців для тренду)
  3. Виберіть "Alle" або "Mobile web" або "Desktop web"
  4. Отримайте графік переглядань

#### **Метод 2: Аналіз категорії (Massviews)**
- **Найкраще для**: Усі астрономічні статті одночасно
- **Як це робити**:
  1. На вкладці Massviews виберіть "Category" як тип імпорту
  2. Введіть повну URL категорії: `https://uk.wikipedia.org/wiki/Category:Астрономія`
  3. Система завантажить усі статті з цієї категорії
  4. Встановіть часовий період
  5. Отримайте зведену статистику

#### **Метод 3: Порівняння мов (Langviews)**
- **Найкраще для**: Порівняння інтересу до астрономії на різних мовах
- **Як це робити**:
  1. Введіть назву статті (англійською)
  2. Система покаже графіки для усіх мов
  3. Знайдіть український графік

### Крок 3: Інтерпретація даних

#### Що означають графіки?
- **Вісь Y (вертикальна)**: Кількість переглядань на день
- **Вісь X (горизонтальна)**: Час (дні, тижні, місяці)

#### На що звертати увагу:
1. **Загальний тренд**: Дані зростають вгору чи падають вниз?
2. **Сезонність**: Чи є регулярні всплески (наприклад, щороку в одному місяці)?
3. **Аномалії**: Чи є раптові великі всплески? (це зазвичай зовнішні подіївідпо)
4. **База часу**: Скільки часу дані збираються? (6 місяців = надійніше)

### Крок 4: Контекстуалізація результатів

Порівняйте астрономію з іншими предметами:

```
Типові дані для порівняння:
- "Математика" vs "Астрономія"
- "Фізика" vs "Астрономія"
- "Біологія" vs "Астрономія"
```

Запитайте себе:
- Чи астрономія зростає швидше за інші науки?
- Чи її переглядання стабільні чи дуже коливаються?

### Крок 5: Сбір додаткових даних

1. **Активність редакторів**:
   - Відвідайте сторінку обговорення астрономічної статті
   - Подивіться на історію редагувань
   - Кількість нових редакцій вказує на активність спільноти

2. **Кількість статей**:
   - Де посилання на категорію "Астрономія"
   - Подивіться, як багато статей у категорії
   - Чи це число зростає з часом?

3. **Якість статей**:
   - Чи астрономічні статті мають повноцінний вміст?
   - Чи вони перекладені з інших мов або оригінальні?

## Приклад інтерпретації даних

### Сценарій 1: ПОЗИТИВНА тенденція (зростання інтересу)
```
Період: Січень 2024 - Вересень 2025

Результат для "Астрономія":
- Січень 2024: ~5,000 переглядань/день
- Вересень 2025: ~8,500 переглядань/день
- Зростання: 70% за 20 місяців

Висновок: Помітне зростання інтересу
Довіра: Середня-висока
```

### Сценарій 2: НЕСТАБІЛЬНА тенденція (не надійна)
```
Період: Січень 2024 - Вересень 2025

Результат для "Астрономія":
- Січень 2024: ~5,000 переглядань/день
- Лютий 2024: 2,000 (падіння через карантин)
- Серпень 2024: 15,000 (піки через кометне?)
- Вересень 2025: ~5,500 переглядань/день
- Коливання: від 2,000 до 15,000

Висновок: Дуже нестабільно, залежить від подій
Довіра: Низька
```

### Сценарій 3: ДУЖЕ НИЗЬКА тенденція
```
Період: Січень 2024 - Вересень 2025

Результат для "Астрономія":
- Вся межа: 500-1,000 переглядань/день
- Немає явного тренду

Висновок: Низький інтерес
Довіра: Можна покластися на висновок про низький інтерес
```

## Закодовані коментарі до інтерпретації

| Результат | Інтерпретація | Повинен ви додати курс? |
|-----------|---------------|----------------------|
| +50-100% зростання + стабільно | Помітне зростання інтересу | Можливо так ✓ |
| +20-50% зростання + дещо волатильно | Помірне зростання | Потребує більше контексту ✓ |
| -10 до +20% | Дуже слабкий тренд | Потребує більше контексту ✗ |
| Падіння більше -30% | Зменшення інтересу | Обережно ✗ |

## Поширені помилки

1. **❌ Інтерпретація раптового всплеску як тренду**
   - Одна новина про астероїд не означає, що інтерес зростає

2. **❌ Ігнорування сезонності**
   - Астрономія може мати сезонні піки (наприклад, у травні при астрономічних конгресах)

3. **❌ Прямим порівнянні з абсолютними числами**
   - Астрономія матиме менше переглядань, ніж "Математика", але обидва можуть зростати

4. **❌ Припущення, що переглядання = навчання**
   - Хтось міг просто випадково натиснути на сторінку

5. **❌ Ігнорування України-специфічних факторів**
   - Військовий конфлікт впливає на освіту та інтернет-використання
